              How LWW-Element-Set Works

              A Last-Writer-Wins (LWW) Element Set uses two sets: an Add Set and a Remove Set, each storing items with their logical timestamps. An item is considered present if it's in the Add Set and either not in the Remove Set, or its timestamp in the Add Set is strictly greater than its timestamp in the Remove Set.

              Turn off the network, add/remove items on both clients independently, and then Sync to see conflict-free resolution.
